# Growth Nations — Official Web Platform

> **Grow Faster. Market Smarter. Scale Bigger.**  
> Production-ready website and digital platform for **Growth Nations** (`https://growthnations.in`).

Growth Nations helps ambitious businesses generate leads, improve their online presence, acquire customers, and scale through digital marketing, technology, automation, and data-driven growth strategies.

---

## 🚀 Core Capabilities & Services

- **Digital Marketing & Paid Media**: High-ROI Meta Ads, Google Ads, YouTube Ads, Performance Marketing, and PPC.
- **High-Intent Lead Generation**: B2B Lead Gen, Real Estate Inquiries, Local Client Acquisition, and Qualification Systems.
- **SEO & Organic Growth**: Technical SEO, Local SEO, Keyword Dominance, and Search Optimization.
- **Social Media Management**: Creative Strategy, High-Converting Reels, and Category Leadership.
- **Technology & Software**: Conversion-Engineered Business Websites, Web Applications (Next.js/React), and Shopify Stores.
- **AI Chatbots & Automation**: 24/7 Conversational AI, Instant WhatsApp Inquiries, and Automated CRM Integration (HubSpot, Zoho).

---

## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vite.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations & Interactions**: [GSAP](https://greensock.com/) (ScrollTrigger) + [Framer Motion](https://www.framer.com/motion/)
- **Media Streaming**: [HLS.js](https://github.com/video-dev/hls.js/)

---

## 💻 Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
The site will be available at `http://localhost:5173/`.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
